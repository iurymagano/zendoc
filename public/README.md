# public/

Arquivos estáticos servidos na raiz do site.

---

## logo.svg, logo-negativo.svg, logo-branco.svg, logo-mark.svg

**O que faz:** versões do logo IAzen para uso fora do React (e-mail, redes sociais, Stripe, documentos).

- `logo.svg`: símbolo com degradê e wordmark escuro, para fundo claro
- `logo-negativo.svg`: símbolo com degradê e wordmark claro, para fundo escuro
- `logo-branco.svg`: tudo branco, para fundo colorido
- `logo-mark.svg`: só o símbolo

**Notas:** gerados da geometria de `components/brand/logo-geometry.ts`; o wordmark está em curvas.

## file.svg, globe.svg, next.svg, vercel.svg, window.svg

**O que faz:** ícones padrão do template do Next.js, sem uso nas telas.
